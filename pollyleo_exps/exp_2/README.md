# Эксперимент 2: Анализ схожести голов внимания в Llama 3.1-8B

## Описание

Эксперимент по анализу схожести голов внимания с использованием метрики L1 (средняя абсолютная разность матриц внимания).

## Структура

```
pollyleo6_exps/exp_2/
├── extract_attention_matrices.py  # Извлечение матриц внимания
├── analyze_head_similarity.py     # Анализ схожести голов
├── head_merging_experiment.py     # Эксперимент с объединением голов
├── run_experiment.py              # Главный скрипт запуска
├── attentions/                    # Сохраненные матрицы внимания
├── plots/                         # Тепловые карты и графики
├── similar_heads.txt              # Топ-10% похожих пар
├── perplexity_trend.png           # График зависимости перплексии
└── perplexity_results.csv         # Данные эксперимента
```

## Запуск

```bash
cd /home/ThunderstormXX/Ridiculous-LLM-Compression
python pollyleo6_exps/exp_2/run_experiment.py
```

## Этапы эксперимента

1. **Извлечение матриц внимания**
   - Загрузка Llama 3.1-8B из `src/checkpoints/llama3.1-8b`
   - Обработка 100 случайных примеров из C4 (первые 128 токенов)
   - Сохранение усредненных матриц внимания

2. **Анализ схожести голов**
   - Вычисление L1 разности для всех пар голов в каждом слое
   - Поиск топ-10% наиболее похожих пар
   - Создание тепловых карт и графиков распределения

3. **Эксперимент с объединением голов**
   - Измерение исходной перплексии на валидационной части C4
   - Постепенное объединение похожих голов
   - Отслеживание изменения перплексии

## Результаты

- `similar_heads.txt` - список наиболее похожих пар голов
- `plots/layer{X}_head{Y}_head{Z}.png` - тепловые карты разностей
- `plots/layer{X}_distribution.png` - распределения L1 разностей по слоям
- `perplexity_trend.png` - график зависимости перплексии от % объединенных голов
- `perplexity_results.csv` - детальные данные эксперимента
